# Portfolio (Spider‑Verse–inspired)

This is a static portfolio scaffold (HTML/CSS/JS) using an original Spider‑Verse–inspired visual theme. Replace the placeholder text, images, and resume with your content.

Quick start

1. Put your uploaded photo at `assets/photo.jpg` and your resume at `assets/resume.pdf`.
2. Open `index.html` in a browser to preview.

Deploy to Vercel

Install the Vercel CLI (optional):

```bash
npm i -g vercel
```

Then run:

```bash
vercel --prod
```

Notes

- This project includes a simple canvas animation and CSS-driven animations. Tweak `styles.css` and `script.js` for more effects.
- All artwork must be original or licensed; do not use official movie assets.
